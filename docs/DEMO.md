# Zero-to-Demo Guide (Stage 9)

This guide verifies the project is runnable end-to-end without modifying source code paths.

## 1. Environment setup

```bash
conda create -n multi-classroom-qos-yolo python=3.10 -y
conda activate multi-classroom-qos-yolo
pip install -r requirements.txt
```

## 2. Quick sanity checks

```bash
# Ensure scripts are executable directly
python scripts/train_detector.py --help
python scripts/infer_single.py --help
python scripts/run_edge_node.py --help
python scripts/run_cloud_service.py --help
python scripts/benchmark_multi.py --help
```

## 3. Unit tests (stage-9 key modules)

```bash
pytest -q tests/test_config.py tests/test_frame_buffer.py tests/test_sampler.py tests/test_scheduler.py tests/test_api.py
```

## 4. Full test suite

```bash
pytest -q
```

## 5. Minimal runnable demo

### 5.1 Start cloud review service (terminal A)

```bash
python scripts/run_cloud_service.py --config configs/cloud/cloud_review.yaml
```

### 5.2 Start edge node for 15 seconds (terminal B)

```bash
python scripts/run_edge_node.py \
  --config configs/streams/demo_4streams.yaml \
  --detector-config configs/detector/yolov8_head.yaml \
  --cloud-config configs/cloud/cloud_review.yaml \
  --workers 1 \
  --duration-sec 15 \
  --status-interval-sec 2
```

Expected output artifacts:
- `outputs/reports/*.jsonl`
- `outputs/reports/*_summary.json`
- `outputs/logs/*.log`

## 6. Benchmark and report demo

```bash
python scripts/benchmark_single.py --config configs/experiments/single_stream.yaml --skip-val
python scripts/benchmark_multi.py --config configs/experiments/multi_stream.yaml --workers 1
python scripts/export_results.py --input-dir outputs/reports
python scripts/visualize_results.py --output-dir outputs/reports
```

Expected artifacts:
- Unified summary JSON/CSV in `outputs/reports/`
- Charts generated by `visualize_results.py`

## 7. One-command stage-8 pipeline demo

```bash
python scripts/run_experiments.py --config configs/experiments/stage8_quick.yaml --mode all
```

Expected artifact:
- `outputs/reports/stage8_<timestamp>/` containing tables, figures, and manifests
